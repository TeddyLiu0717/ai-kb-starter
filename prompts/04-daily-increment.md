# /每日增量（自动化任务可用）

执行今天的知识库增量维护：

1. 扫描我配置的信息源（如飞书/Notion/书签文件夹/下载目录），列出「自上次运行以来新增或更新」的对象，读上次水位记录，不要漏更新
2. 新对象走 Capture（原文入 raw/，不完整/无权限的标记 blocked 原因，不许伪报完成）
3. 可执行对象每批 ≤ 10 篇走 Ingest，过质量门再进入 wiki/
4. 运行 `python scripts/kb.py doctor`，输出当日回执：新增 X 页 / 更新 X 页 / 阻塞 X 项（列原因）/ 体检结果
5. 推进水位记录；无法自动判断的事情列成清单等我决定，不要猜
